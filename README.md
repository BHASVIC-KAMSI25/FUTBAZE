# ⚽ FUTBAZE 24/25

FUTBAZE is a football analytics platform built with **Python, Pandas and Streamlit**.

The project takes player statistics and turns them into interactive player profiles, position-adjusted productivity ratings, player comparisons and performance visualisations.

It also includes **My FUTBAZE**, allowing users to record their own match performances and track their statistics over time.

## 📊 Features

### Player Analysis

Select a player and explore their performance through:

* Player information
* Attacking productivity
* Defensive productivity
* Performance radar
* Basic statistics
* Attacking statistics
* Passing and progression statistics
* Defensive statistics
* Goalkeeping statistics
* Discipline statistics
* Per-90 statistics

### Player Comparison

Compare two players from the same position using:

* Performance radar charts
* Attacking statistics
* Passing and progression statistics
* Defensive statistics
* Per-90 statistics
* Side-by-side statistical comparisons

The comparison tables highlight differences between the selected players.

* Shots

* Passes
* Successful passes

Goalkeepers can additionally record:

Recorded matches are stored during the session and can be viewed through match history, performance trends and career statistics.

### 📈 Performance Ratings

FUTBAZE uses a position-aware statistical model.

Players are grouped into:

* GK
* DF
* MF
* FW

The model uses position-adjusted percentile rankings, weighted statistics and playing-time reliability.

Players with at least **900 minutes** are used as the main comparison group.

Statistics that depend on playing time can also be converted into **per-90 values**:

$$
\text{Per 90} =
\frac{\text{Statistic}}{\text{Minutes Played}}
\times 90
$$

Scores are calculated on a 0–100 scale.

### 🧮 Rating Bands

|   Score | Rating        |
| ------: | ------------- |
|  64–100 | Elite         |
| 50–63.9 | High Standard |
| 30–49.9 | Standard      |
| 20–29.9 | Mediocre      |
|  0–19.9 | Poor          |

These ratings are part of the FUTBAZE analytical model and are not official player ratings.

## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/BHASVIC-KAMSI25/FUTBAZE.git
```

Move into the project directory:

```bash
cd FUTBAZE
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

The application will then be available locally through Streamlit.
